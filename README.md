## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/sarika25/portfolio.git
```

### 2. Navigate to the project

```bash
cd portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```

## 📧 Contact Form

The portfolio uses **EmailJS** to allow visitors to send messages directly through the contact form.

The flow is:

```text
Visitor
   ↓
Portfolio Contact Form
   ↓
EmailJS
   ↓
Personal Gmail Inbox
```

No separate backend server is required for the contact form.
